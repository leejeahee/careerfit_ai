## 1. 문서 목적



이 문서는 CareerFit AI 프로젝트에서 사용할 AI 모델을 선택하기 위해 작성한다.



공개 리더보드 점수만 보고 모델을 고르지 않고,

내 프로젝트의 실제 사용 목적에 맞게 직접 질문하고 비교한다.



CareerFit AI의 모델 선택 기준은 다음과 같다.



* 한국어 답변 품질

* 취업·직무 상담 적합성

* 채용공고 요약 능력

* 사용자 맥락 반영 능력

* 환각이 적은 답변

* 응답 속도

* 비용 또는 무료 사용 가능성

* API 연결 난이도

* 라이선스와 사용 제한

## 4. 평가 방식



모델 평가는 1차 정량 평가와 2차 정성 평가로 나눈다.



### 4-1. 정량 평가



각 항목을 1점부터 5점까지 평가한다.



| 점수 | 의미 |

| -- | -------- |

| 5점 | 매우 좋음 |

| 4점 | 좋음 |

| 3점 | 보통 |

| 2점 | 부족함 |

| 1점 | 사용하기 어려움 |



### 4-2. 정성 평가



점수만으로 판단하지 않고, 실제 답변을 읽고 아래 내용을 기록한다.



> **고도화 (2026-07-06 반영):** 응답 속도는 네트워크 상태·API 서버 부하에 따라 같은 모델도 실행마다 크게 달라질 수 있다(예: Gemini는 같은 프롬프트로 4초대 응답과 88초대 응답이 모두 관측됨). 응답 속도 점수는 **최소 3회 반복 측정 후 중앙값**을 기준으로 매기고, 단일 실행 결과만으로 속도를 단정하지 않는다.



* 답변이 자연스러운가?

* 사용자의 전공, 경험, 목표를 반영했는가?

* 없는 정보를 지어내지 않았는가?

* 너무 일반적인 조언만 하지 않았는가?

* 실제 포트폴리오 개선에 도움이 되는가?

* 답변 형식이 보기 쉬운가?

* 한국어 표현이 어색하지 않은가?

## 14. 향후 개선 과제



2026-07-06 1차 테스트에서 발견된, 후속 조치가 필요한 항목이다.



* **Gemini 응답 속도 재측정**: 동일 프롬프트로 4초대와 88초대가 모두 관측됐다. 최소 5회 반복 측정 후 중앙값·표준편차를 8번 비교표에 추가하고, 편차가 재현되면 기본 LLM을 Mistral로 교체할지 결정한다.

* **임베딩 모델 자체 벤치마크**: 현재 `rag_service.py`는 ChromaDB 기본 임베딩 함수(`all-MiniLM-L6-v2`)를 그대로 쓰고 있고 별도 평가를 거치지 않았다. 한국어 채용공고 검색 정확도 기준으로 `ko-sroberta`, `multilingual-e5` 등 한국어/다국어 특화 임베딩 모델과 비교 후 10번 표를 갱신한다.

* **Hugging Face 모델 재선정**: `Qwen2.5-0.5B-Instruct`는 이번 테스트에서 실사용 불가 수준으로 확인됐다(7번 참고). 최소 7B급 Instruct 모델(`Qwen2.5-7B-Instruct`, `Mistral-7B-Instruct` 등)로 교체 후 동일한 테스트 질문 세트(6번)로 재평가한다.

* **테스트 질문 세트 전체 실행**: 이번 1차 채움은 6-2의 질문 1개만 5개 provider에 실행한 결과다. 6-1(핵심 질문 5개)·6-3(환각 확인)·6-4(형식 준수)까지 전부 돌려서 항목별 점수의 신뢰도를 높인다.
