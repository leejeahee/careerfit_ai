## 1. 5일 동안 가장 인상 깊었던 경험 1가지

LLM모델 API를 호출해서 내가 의도한 인공지능 모델을 제작, 배포를 완료한 경험이 가장 인상 깊었다. 



## 2. 가장 오래 막혔던 구간

막힌 구간: 코딩 작업 자체보다는 2일차에 커서에서 antigravity로 ide를 이관하고 터미널에 claude code CLI를 심는 작업이 가장 어려웠다.

원인: 기존에 웹앱 개발을 antigravity에서 하고 있었기 때문에 사용이 익숙한 IDE로 작업을 이어가고 싶었다. 커서는 무료 사용량 quota에 너무 빠르게 도달하는 경향이 있어 마음에 들지 않았다. 또한 클로드 코드는 터미널에서 실행해야 했기에 사용법을 익히는 데 어려움이 있었다. 

해결 방법: 내 생각보다 AI는 똑똑했다. IDE 이관 전 커서에서 사용했던 .mdc등의 파일을 자동으로 무시하고, 클로드가 참고하는 파일을 스스로 만들었다. 또한 클로드 코드 익스텐션을 따로 설치해야하는 줄 알았으나 터미널에서 claude 명령어만 치면 자동으로 내 클로드 유료 계정과 연결된 터미널 클로드 세션이 켜졌다. 



## 3. 처음으로 "이게 되는구나" 싶었던 순간

LLM API를 동작시켜본 경험이 있었기에 새롭다고 느끼지는 못했지만, 약 3년 전 llama와 gemini API를 통해 팀단위로 인공지능 모델을 개발 했을 때보다 인공지능 에이전트 및 하네스를 활용한 모델 개발이 얼마나 간편해졌는지 체감하였다. 또한, requirements.txt 내에 있는 프로세스들을 pip install -r requirements.txt를 이용하여 한 번에 다운로드되는 것을 처음 알게 되어 신기했다.


## 4. 내 서비스의 아쉬운 점

아무래도 데이터 부족으로 인한 서비스 부실이 가장 아쉬운 부분이다. 별다른 파인튜닝 없이 LLM을 그대로 이용한 것이기 때문에(RAG를 이용하긴 했지만) 유사도 측정 알고리즘 관련된 작업을 수행하지 않았다는 점이 아쉽다. 


## 5. 다음에 혼자 도전해보고 싶은 것

내가 직접 파인튜닝한 LLM을 적합해보고 싶다. 또한, 프론트엔드를 덜 AI틱하게 다듬어 더 세련되고 깔끔하게 변경하고 싶다.
