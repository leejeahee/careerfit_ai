# PROJECT_PLAN.md — CareerFit AI 프로젝트 기획 초안



## 1. 문제 정의

# 취업 또는 공모전을 준비할 때 불편했던 점
- 나의 직무와 관련된 취업 공고, 회사 평점 등을 검색하는 데에 시간이 많이 소요
- 나의 직무와 관련되면서 내 스케줄을 방해하지 않는 공모전을 찾기 어려움
- 회사마다 어떤 포트폴리오를 중시하는지에 대한 정보를 탐색하기 어려움

# Career Fit AI가 어떻게 문제를 해결하는가?
- 본인의 SSO를 통해 접근 가능한 학교 사이트, 커뮤니티 등을 참고하여 나의 직무 기반 공고, 평점 스크랩
- 내 스케줄(구글캘린더 등)을 명시하면, 내가 하고자하는 공모전을 캘린더에 출력해줘서 스케쥴링을 용이하게 함
- 인터넷 정보 탐색을 통해 최근 해당 회사가 중시하는 포트폴리오 정보 스크랩

## 2. 사용자 정의

- 대상: 취업 준비생 및 스펙을 쌓으려고하는 대학생



- 사용 시나리오:

1. 사용자가 전공, 보유 스킬, 관심 직무, SSO 진입을 위한 아이디와 패스워드를 입력한다.

2. CareerFit AI가 데이터를 검색해 역량 매칭 결과를 반환한다.

3. 어떤 데이터를 기반으로 답변했는지 출처를 함께 표시한다.



## 3. 데이터 계획

- 취업 공고 컬럼: 회사명, 직무명, 직무기술, 요구 스펙, 우대 사항, 지원자격, 업무 내용, 마감일

- 공모전 컬럼: 주최사명, 공모전 제목, 필요 기술, 지원자격, 업무 내용, 마감일

- 데이터 출처: 강사 제공 목업 CSV (3일차)
